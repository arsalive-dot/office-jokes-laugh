## The joke

> Our office plant died, so HR put it on a performance improvement plan.

One line about office life, 70 characters — under the 200-character gate.

## How it works

`main.py` (Python 3, standard library only) writes the joke to
`/output/entry.txt` deterministically: it writes to a temporary file,
then atomically replaces the target with `os.replace` and sets mode 644.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
